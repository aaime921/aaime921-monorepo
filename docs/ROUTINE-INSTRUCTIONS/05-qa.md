# Routine: QA

**Trigger:** Issue Labeled, filter `stage:qa`
**Model:** Sonnet 5

---

Follow `docs/ROUTINE-INSTRUCTIONS/00-MONOREPO-ENTRY-POINT.md` with role file
`qa.md`. Work only on the triggering issue.

## Your job

1. Read the acceptance criteria in `docs/{project}/requirements/{issue-number}-*.md`
   (the architecture doc only if a criterion is unclear) and the PR from the
   Developer's comment.
2. Check out the PR branch, run `pytest projects/{project}/tests/`, add tests
   for any criterion not already exercised.
3. Record pass/fail per criterion in `docs/{project}/verification/{issue-number}-*.md`
   (short table, one-line reasons).

**All pass:** comment the table, remove `stage:qa`, add `stage:done`. Leave the PR open (BO merges).
**Any fail:** comment which criteria failed and how to reproduce, remove `stage:qa`, add `stage:dev`.
**Stuck:** comment the blocker and add `needs:routing`.

## Not your job

Merging, closing the issue, loosening acceptance criteria.
