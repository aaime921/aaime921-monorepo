## 9. Discrepancies Found

- **Issue #1 (now fixed):** `scale_data.weight` is in deci-kilograms, not
  kilograms — `EufyConnector.normalize()` was passing it straight through
  unconverted. Found via live evidence (real payloads showing values like
  `829.5`/`883.5`, physically impossible as kg), root-caused, fixed, and
  regression-tested against the real captured values through the full
  pipeline (requirements → design → implementation → independent QA
  verification). Merged to `main` at `0543d91`. This is exactly the category
  of discrepancy this protocol exists to catch: a mock/fixture assumption
  (`test_eufy_connector.py` previously used pre-scaled plausible values like
  `75.4`/`80.0`) that live payload magnitudes contradicted.
