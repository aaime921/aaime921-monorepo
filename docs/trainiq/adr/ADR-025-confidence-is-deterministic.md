# ADR-025 — Confidence Is Deterministic

**Status:** Accepted (Phase 0B, Milestone D — Coach Engine Decision Architecture)
**Origin:** Current research on LLM confidence estimation, reviewed during Milestone D, found LLM self-reported confidence to be consistently unreliable and systematically overconfident — a documented, repeated finding, not a one-off concern.

## Context

If the Coach's confidence score could be generated by the language model itself, the entire Confidence Propagation chain (ADR-017) built through Milestones A–C would be undermined at the last step, where it matters most to the athlete.

## Decision

The Confidence Score is never generated by an LLM. It is always computed deterministically, derived exclusively from Confidence Propagation (ADR-017) and Evidence Density (ADR-024). The language model's role regarding confidence is purely communicative — narrating a number it did not produce.

## Consequences

- Considered by the Chief Architect to be one of the two most consequential decisions of the entire project (alongside ADR-026), because it protects TrainIQ from an entire category of future problems: model changes, provider changes, and version-to-version behavioral drift in the LLM never affect what confidence means.
- Directly generalized in Epic 6/7's implementation: `compute_training_load()`'s Unknown/reason mechanism and `source_confidence`'s field-completeness ratio are both fully deterministic, with no model involvement — built years before any Coach Engine code exists, but already consistent with this ADR by construction.
